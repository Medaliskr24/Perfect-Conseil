PERFECT CONSEIL – PHP + MySQL SITE WITH SECURE ARTICLES DASHBOARD
==================================================================

WHAT YOU UPLOAD
  The whole content of the folder "site/" goes into your web root (public_html), including hidden files (.htaccess).

BEFORE YOU INSTALL (IMPORTANT – your old site was hacked)
  1. Delete ALL old WordPress files from the web root (wp-admin, wp-content, wp-includes, wp-*.php ...). Backdoors usually hide there.
  2. In your hosting panel / phpMyAdmin create a NEW empty database and a NEW database user with a NEW long random password.
     Do NOT reuse the old WordPress database user: its password must be considered compromised.
     (You can drop the old wp_ tables, or keep them out of this new database.)
  3. Switch PHP to 8.1 or newer in the hosting panel if possible (PHP 7.4 no longer receives security fixes).
     The code works on PHP 7.4 to 8.3 and MariaDB/MySQL.
  4. Make sure HTTPS is active on the domain.

INSTALL (2 minutes)
  1. Upload "site/" content.
  2. Open  https://YOUR-DOMAIN/install.php
  3. Fill in: database host (localhost), database name, database user, database password,
     then YOUR admin email and a strong password (12+ characters). Click Install.
  4. The installer creates the tables, your admin account and the config file, then deletes itself.
     If it says it could not delete install.php, delete it manually right away.
  5. Log in at  https://YOUR-DOMAIN/admin/login.php

  Manual alternative: import database.sql in phpMyAdmin, but the installer is simpler because it also creates the admin account.

USING THE DASHBOARD (Arabic interface)
  - "+ مقال جديد": title, category, date, description, text (bold, titles, lists, quotes, links), cover image, status.
  - Status: published / draft. A future publication date = scheduled (appears automatically on that date).
  - The SEO checklist on the side helps you write articles that rank better.
  - Articles appear on  /actualites.html  and each has its own address  /actualites/<slug>.html
  - /sitemap.xml is generated automatically from the database.
  - "حسابي": change your email and password.

SECURITY BUILT IN
  - Passwords hashed with bcrypt (cost 12); never stored in clear text.
  - Login lockout: 6 failed attempts per IP/email -> blocked for 15 minutes. Same error message for wrong email or password.
  - Sessions: HttpOnly, SameSite=Strict, Secure on HTTPS, new session id at login, expire after 2 hours of inactivity.
  - CSRF token on every form (login, save, delete, logout, account).
  - All database queries are prepared statements (no SQL injection).
  - Article HTML is cleaned on the server with a strict whitelist (p, titles, lists, bold, italic, quotes, links http/https/mailto): scripts, iframes, event handlers and javascript: links are removed.
  - Cover images: type checked, re-encoded and resized on the server, random file names, PHP execution disabled in /uploads.
  - Admin pages send a strict Content-Security-Policy (no inline scripts), no-store caching and noindex.
  - Folders inc/ and tpl/ are blocked from the web. Database password is only in inc/config.php (permissions 640).

BACKUPS
  Export the database regularly from phpMyAdmin (Export > Quick > SQL) and download the uploads/ folder.

IF YOU SEE "500 Internal Server Error" AFTER UPLOAD
  Some hosts do not allow the "Options" line in .htaccess: delete the line "Options -Indexes" in .htaccess (and in uploads/.htaccess,
  admin/.htaccess) and try again.

TO MODIFY THE STATIC PAGES
  The pages (home, services...) are generated by build.py from the assets folder (python build.py). Ask for changes and upload the new site/ folder
  (do NOT overwrite inc/config.php or the uploads/ folder).
